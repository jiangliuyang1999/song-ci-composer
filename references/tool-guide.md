# 工具使用与校验边界

## 运行与查询

脚本仅使用 Python 标准库及 Skill 内置资产；从 Skill 根目录运行 `python3 scripts/ci_tool.py`，其他目录使用脚本绝对路径。以各子命令 `-h` 为参数依据。

```bash
python3 scripts/ci_tool.py list --query "浣溪沙"
python3 scripts/ci_tool.py rhyme --rhyme "第七部" --tone level --limit 30
python3 scripts/ci_tool.py prepare --theme "暮春送别" --bank-limit 30
```

`list` 支持规范名、繁体名及别名匹配。歧义别名须改用规范名；可根据用户给出的字数、例词等信息消歧，否则请用户选择。未收录时给出相关可用候选，不罗列整个词牌库。若用户提供可信词谱，可依其创作或人工检查，但不能宣称通过本工具的确定性校验。

## 默认推断与体式

`prepare` 对未指定的词牌与词人，在命中候选中按适配分数加权抽取；无命中时从常见备选中随机选择。候选只有一个时仍可能重复，不能把抽样解释为不重复保证。未约束韵系的兼容韵部顺序也会打乱，不再固定优先沿用例词原韵。显式指定项不参与随机替换，体式仍使用下述常用默认值。

每次返回 `exploration.briefs` 三组不同的构思提示，用于拓展视角、起笔、推进、情绪与结尾；须根据主题筛选和具体化，不能照单拼接。日常创作省略 `--seed`；调试时可传整数以复现同一版本、同一日期与相同参数下的约束抽样及提示，但不能保证生成正文完全相同。检查已有作品不调用此抽样流程。

用户未指定主题时，脚本按执行环境日期生成季节场景，再依主题推荐词牌、依主题和词牌推荐词人。季节采用二至四月春、五至七月夏、八至十月秋、十一月至一月冬的近似划分。节日候选使用公历近似日期窗口，并非农历换算；不得据此声称当天就是节日。用户指定时地、季节或节日时将其明确写入 `--theme`，不让默认推断覆盖。

从 `inference` 读取实际返回的依据，不假定存在未返回的节日字段。不必向用户列出候选集、随机下标或内部采样信息。

用户指定体式时传 `--variant`，可用“正体”“格二”或模板 ID。未指定时脚本常用体式例外为：临江仙格八、水调歌头格三、念奴娇格二、忆江南格二、南乡子格六、江城子格五、声声慢格十三；其余通常取正体。实际选择以 `prepare` 返回值为准，复验锁定 `pattern.id`。

“浪淘沙”与“浪淘沙令”在资产中是独立条目：前者唐体单调二十八字，后者默认李煜体正体、双调五十四字。不要因通俗称呼相近而静默互换；用户给出的篇幅或例词与名称冲突时先消歧。

## 韵脚约束

| 输入 | 含义 |
| --- | --- |
| `第七部` / `cilin-07` | 从该《词林正韵》韵部选字 |
| `十四寒` | 使用该韵目所属韵部，不限定为该韵目的字表 |
| `寒、山、阑` | 押韵句末字只可从指定字集中选，仍须同部且符合声调 |
| `an` | 附加现代普通话韵母检查，见下方能力边界 |

单韵系用 `--rhyme`；多韵系用分号分隔的 `--rhymes`，可只指定部分韵系，其余由 `prepare` 选择。例如：

```bash
python3 scripts/ci_tool.py prepare \
  --cipai "减字木兰花" --theme "春日送别" --poet "欧阳修" \
  --rhymes "rhyme-1=第三部;rhyme-2=第七部;rhyme-3=第三部;rhyme-4=第六部"
```

复验时仍用同一 `--rhymes`，并补齐创作时选定的未指定组。上述第一、第三韵系可以复用第三部；相邻组同部会触发工具的 `adjacent_rhyme_group` 规则。`--rhyme` 与 `--rhymes` 互斥，不对多韵系使用全局 `--rhyme`。

韵脚句尾必须满足同部及指定约束；词谱未标韵脚的句尾必须避开全篇各韵系实际采用的韵部，任一候选读音同部即为硬错误，平仄不同、叠字或叠词均不豁免。未指定韵部且韵脚有多个候选韵部时，优先选取同时满足句尾避韵和相邻换部的组合。句尾缺少古韵读音时不能确认避韵，按硬错误处理。

**现代韵能力有限**：当前 `validate` 在检查拼音韵母时仍执行《词林正韵》同部和古典声调检查，`prepare` 的现代韵候选组合也可能报兼容冲突。因此拼音参数不是独立的新韵模式。只有用户明确要求时才使用，并说明双重约束；不能把用户的新韵要求悄悄改成古韵，也不能宣称已经完整支持新韵校验。

指定现代韵母时，非韵脚句尾还须避开各组指定韵母；任一现代读音命中即报错，现代读音缺失也不能判为通过。

## 正文输入

优先使用 `validate --file` 传入 UTF-8 正文，避免长文本的 shell 引号问题。短文本可用 `--text`；两者互斥。用与 `pattern.rows` 一致的换行或中文标点分句，不把题名、注释、署名或译文放入输入。

```bash
python3 scripts/ci_tool.py validate \
  --cipai "减字木兰花" --variant "正体" \
  --rhymes "rhyme-1=第三部;rhyme-2=第七部;rhyme-3=第三部;rhyme-4=第六部" \
  --file /tmp/ci-draft.txt
```

例中体式必须与实际约束包一致；正式复验优先使用返回的模板 ID。若只检查已有词作且用户未指定韵部，不添加 `prepare` 推荐韵部，以免把合法原韵当成错误；让 `validate` 从正文检查押韵关系。

## 结果与诊断

`prepare` 成功退出不保证约束可用。检查 `pattern.sourceValidation.errors`、`pattern.sourceValidation.is_valid` 和 `compatibilityIssues`。源数据错误须披露，不自行猜测修补；缺失校验元数据不等于已经验证。

`validate` 退出码 0 对应 `passed: true`，2 表示校验错误；参数错误也可能返回 2，须读取输出，不能把无 JSON 的运行失败当成格律问题。其他执行失败不得报为词作通过。

| 字段或类型 | 处理 |
| --- | --- |
| `line_count` / `length` | 对照模板修复句界、句数或字数 |
| `tone` | 修复指定位置平仄，保持文意 |
| `unknown_rhyme` / `rhyme_group` | 查韵脚读音与韵部；无法核实时换字或标待核 |
| `specified_rhyme_group` / `specified_end_characters` / `modern_final` | 检查是否满足用户约束，不静默放宽 |
| `adjacent_rhyme_group` | 检查各韵系候选与前置押韵错误，再判断是否需要整组换韵 |
| `non_rhyme_ending_same_group` | 硬错误；按行号、位置将非韵脚句尾换成不属于任一已采用韵部的字 |
| `non_rhyme_ending_modern_final` | 硬错误；非韵脚句尾须避开各组指定的现代韵母 |
| `unknown_non_rhyme_ending` | 硬错误；句尾读音缺失，不能确认避韵，须换字或标待核 |
| `unknown_tone` / `ambiguous_tone` | 属于警告，仍须按语义核音；无法确认时换字或明确待核 |
| `repeated_rhyme_character` | 优先换同部、同声调韵脚；有意叠句等保留时说明，不能漏审 |
| `non_rhyme_same_group` | 仅针对句中非韵脚字的审美提示；尝试换字，结合多音字当前读法与文意决定是否保留 |
| `repeated_character` | 审美提示；优先减少无意重复，保留有意修辞及必要专名、虚词 |

脚本在重复用字检查中自动豁免部分相邻叠字、叠词，不等于识别了所有修辞，也不豁免句尾避韵。`non_rhyme_same_group` 按所选韵部扫描全文句中非韵脚字；非韵脚句尾另作硬性检查，错误同时写入 `errors` 与对应 `lineChecks[].issues`，导致 `passed: false`、退出码 2。

声调检查遇到古韵字库缺字时可能回退现代普通话；多音字也只是枚举可能声调，没有证明具体语境中的读音。模板分阕和韵系经过脚本归一化、推断，遇特殊换韵、叠韵或与用户所据词谱不一致时，先核实具体体式，不为让工具通过而擅改原作。交付结论应表述为“按本地模板与字库检查”，对未核实的古音或体式保留限定。
